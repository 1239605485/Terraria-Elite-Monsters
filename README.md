# Elite Monsters（正式版）

## 1.4.6 名称显示修复

- 新增烈焰、寒霜、吸血、分裂、狂暴、深渊六种可见词缀，并实现对应的属性或 AI 效果。
- 精英等级与词缀使用 `NPC.whoAmI` 参与确定性生成，降低多人联机两端随机结果不同的风险。
- 增加不可伤害、无敌和可捕捉 NPC 过滤，避免特殊对象被转化。
- 保留稳定的 `SetDefaults` Postfix 初始化路径，避免改变原版 NPC 初始化时序。
- 名称 Hook 改为优先从 `FullName`/`TypeName` 等属性获取 Getter，再自动枚举当前游戏版本的 NPC 名称方法；兼容 `get_*Name`、`Get*Name` 以及 Android 元数据将字符串标记为指针的情况。
- 稀有/传奇奖励只有在物品成功生成后才标记完成，生成失败可以由后续回调重试。
- 名称源改为只安装一个最匹配的 `NPC` 名称 Getter，恢复精英名称和词缀显示；不再批量安装名称 Hook，避免 Android 启动阶段崩溃。
- 普通精英获得低频冲刺，稀有精英获得更高频冲刺；传奇精英保留分类型挑战 AI。
- 普通精英掉落少量药水和进度材料；稀有精英掉落进度材料与实用原版装备；传奇精英保留 70% 普通宝匣/30% 环境匣，并额外掉落进度材料。

一个运行于 Terraria Android ARM64 的分级精英怪模组。

作者：**liuxin**  
当前版本：**1.4.6**

## 模组功能

Elite Monsters 会将普通敌怪转化为精英怪，让探索过程中出现更有挑战性的战斗。

### AI 强化

- 所有精英怪会更积极锁定当前玩家目标。
- 普通精英获得低频短距离冲刺，稀有精英获得更高频短距离冲刺。
- 传奇近战/冲锋怪：距离较远时按冷却瞬移到玩家侧后方，并进行短突进。
- 传奇远程/法师怪：周期性横向拉扯和换位，降低玩家站桩输出的收益。
- 传奇飞行怪：加入侧向偏移的蛇形追击，不再沿直线靠近。
- 传奇蠕虫/特殊怪：周期性斜向突袭或规避移动。
- 传奇生命低于 35% 时只触发一次狂暴，接触伤害提高 25%。
- 传奇 AI 只在单机或服务器侧改变位置/速度；多人客户端不重复触发瞬移。
- 所有行为仍叠加在原版 `NPC.AI` 之后，不替换原版攻击和投射物逻辑。

### 词缀效果

- **烈焰**：伤害提高 10%，周期性进行短冲刺。
- **寒霜**：防御提高 5，并进一步降低击退效果。
- **吸血**：每隔一段时间恢复少量生命。
- **分裂**：首次降至半血时恢复 10% 最大生命并进行一次冲刺。
- **狂暴**：生命较低时进入一次狂暴，接触伤害提高 25%。
- **深渊**：生命和伤害提高，并周期性进行短冲刺；传奇精英会叠加原有的特殊移动。

词缀效果只使用现有 NPC 字段和 AI Hook，不依赖不稳定的自定义投射物或 NPC 生成重载。

### 击杀奖励

- 三档精英都会大幅提高原版 `NPC.value`，金币倍率随游戏模式、游戏进度和精英等级叠加。
- 普通精英在原版掉落处理完成后额外掉落少量药水和 1 份当前进度材料。
- 稀有精英额外掉落 1 份当前进度材料和 1 件实用原版装备。
- 传奇精英额外掉落 1 个宝匣：困难模式前 70% 金匣、困难模式后 70% 钛金匣，30% 按当前环境选择环境匣，并再掉落 1 份当前进度材料。
- 奖励通过原版 `Item.NewItem` 生成，并在多人客户端跳过，避免客户端重复生成。

## 其他规则

- 友好 NPC、城镇 NPC、Boss、无敌 NPC、不可受伤 NPC 和可捕捉 NPC 不会被转化。
- 同一个 NPC 实例不会被重复强化。
- 金币奖励完全使用 Terraria 原版金币机制。
- 本版本不添加自定义物品或虚构材料；稀有奖励和环境匣全部使用 Terraria 原版物品。
- 当前源码按难度递增设置精英生成概率：普通 20%、专家 30%、大师 40%、传奇 50%。
- 游戏进度通过困难模式、机械 Boss、世纪之花、石巨人和月亮领主进度判断。
- 如果奖励物品生成 API 暂时失败，奖励不会被提前标记为已领取，后续 `NPCLoot` 回调仍可重试。

## 生成概率

`EliteMonsters/mod.c` 中的配置如下：

```c
static const int g_spawn_chance_percent[ELITE_MODE_COUNT] = {
    20, 30, 40, 50
};
```

数组顺序为：普通、专家、大师、传奇（天顶世界特殊种子）。旅途/Creative 档仍使用普通档。

每个已经转化为精英的敌怪还会随机获得一个等级：

- 普通精英：70%
- 稀有精英：25%
- 传奇精英：5%
